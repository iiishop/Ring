## Release Definition: v0.2.0-alpha

Latest tag is `0.0.3-alpha`. The codebase has evolved far beyond (v0.1.2 features merged). Version is significantly out of sync with reality. We jump to v0.2.0 based on what already exists.

**In this release:**
- Version jump `0.0.3-alpha` → `v0.2.0` (bump to match existing capability)
- NSIS installer: one-click install, Start Menu entry, system uninstall entry
- CI: tag-triggered, builds `.exe`, builds installer, generates changelog, creates GitHub Release

**Not in this release:**
- No new window management features
- No auto-start / system tray
- No configuration UI

## Product Roadmap (Beyond This Release)

Ring's future direction:
- **Advanced layouts**: custom grid layouts, saved workspace profiles
- **Background mode**: system tray + auto-start
- **Configuration**: configurable hotkeys, snap regions, monitor preferences
- **i18n**: English support
